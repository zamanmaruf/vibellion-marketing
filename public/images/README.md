# Background Image

Place your background image file here and name it `bg-food.jpg`.

The image should be:
- High resolution (at least 1920x1080, preferably larger)
- Optimized for web (JPEG or WebP format)
- The gourmet food photography image you want to use as the site background

The current setup expects the file at: `/public/images/bg-food.jpg`

You can also update the path in `app/globals.css` if you prefer a different filename or location.
